# 2025-PC-1ANOS-1TRI-Snake-Project

## Descrição do Projeto

Este projeto é uma implementação didática do clássico jogo da cobrinha (Snake) utilizando JavaScript com a biblioteca gráfica P5.js. O objetivo principal é servir como um recurso pedagógico prático para ensinar conceitos fundamentais de programação a estudantes iniciantes, especialmente adolescentes que estão começando sua jornada na programação.

## Como o projeto está organizado?

O desenvolvimento do jogo é estruturado em etapas progressivas, cada uma focada em conceitos específicos:

| Etapa   |      Funcionalidade      |  Conceitos Aprendidos |
|----------|:-------------:|:------:|
| 1 |  Desenho da grade | Loops, canvas e formas geométricas |
| 2 |  Movimento automático da cobra   |   Classes, objetos, vetores e animação básica |
| 3 | Controle com teclado |    Eventos de teclado e interação do usuário |
| 4 | Posicionamento e consumo da comida |    Posicionamento aleatório e colisões simples |
| 5 | Crescimento da cobra |    Manipulação de arrays e lógica condicional |
| 6 | Condição de derrota (Game Over) |    Detecção de colisões complexas |
| 7 | Reinício do jogo |    Gerenciamento de estado e reinicialização |
| 8 | Sistema de pontuação |    Contadores e exibição dinâmica de textos |
| 9 | Personalização e melhorias visuais |    Criatividade, estilo visual e customização |

## Objetivos educacionais

1. Introduzir lógica de programação com conceitos essenciais como estruturas condicionais, loops, eventos e arrays.
2 .Desenvolver gradualmente o entendimento da criação e organização de um projeto de programação.
3. Estimular o pensamento lógico, a resolução de problemas e a criatividade através da personalização do jogo.

## Tecnologias utilizadas

[P5.js](https://p5js.org/): biblioteca gráfica JavaScript simples e intuitiva, excelente para projetos educacionais e artísticos.
